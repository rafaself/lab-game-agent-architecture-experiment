# Game UX and Readability

Use this skill when shaping or reviewing the player-facing interface and feedback. It does not choose an art style or replace implementation-specific accessibility requirements.

- Map important player actions and game-state changes to clear, timely feedback.
- Make the primary controls discoverable and consistent across menus and play.
- Show the information needed for the current decision, including the required health, upgrade, room, or objective state.
- Distinguish the player, enemies, attacks, rewards, hazards, and interactive elements. Do not rely on color alone to communicate a critical difference.
- Use audio to reinforce important events, not as the only signal for a gameplay-critical event.
- Prefer focused cues and readable hierarchy over extra interface elements or effects.

When useful, report the player state or action, what the player needs to perceive, and the proposed visual, text, or audio cue. Respect the supplied platform, controls, and visual direction.
