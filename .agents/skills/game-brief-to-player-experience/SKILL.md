# Game Brief to Player Experience

Use this skill for game concept and brief work. For implementation-only requests, follow the supplied specification without adding a design phase.

- Read the brief and separate explicit requirements, recommendations, options, and unknowns.
- State the intended player experience and express it as a short, repeatable core loop.
- Identify only the systems needed to support that loop and the requested scope.
- Record assumptions and unresolved decisions separately; do not silently turn them into requirements.
- Keep the design within the user's scope. Preserve the source brief when summarizing or refining it.

Return a concise design brief with the player promise, core loop, essential systems, scope boundaries, and any assumptions that affect implementation.
